# DriveClaw

moltBOT Desktop Control Panel - 一个基于 Electron 的桌面控制面板应用。

## 技术栈

- Electron
- React 18
- TypeScript
- Vite

## 开发

```bash
# 安装依赖
npm install

# 开发模式
npm run electron:dev

# 构建
npm run electron:build
```

## 功能

- Dashboard 仪表盘
- Chat 聊天
- Channels 频道管理
- Models 模型管理
- Skills 技能管理
- Memory 记忆管理
- Cron Manager 定时任务
- Heartbeat 心跳监控
- Settings 设置
